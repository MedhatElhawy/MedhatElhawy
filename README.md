* **[VentureAgent](https://github.com/MedhatElhawy/VentureAgent) — Orange Digital Center Graduation Project**  
  Autonomous multi-agent startup valuation platform combining hybrid vector search (BM25 + FAISS) with LLM-powered financial reasoning, served through production-ready FastAPI REST APIs and an interactive Gradio interface.

* **[Automotive Diagnostics RAG Assistant](https://github.com/MedhatElhawy/automotive-diagnostics-rag-assistant) — ITI Graduation Project**  
  Domain-specific Retrieval-Augmented Generation system for automotive troubleshooting manuals, delivering citation-backed repair procedures through semantic retrieval and context-aware generation.

* **[Cyber Threat Hunter](https://github.com/MedhatElhawy/cyber-threat-hunter)**  
  AI-powered threat intelligence tool that uses intelligent agents to detect vulnerabilities and security anomalies in system logs, with log parsing and event correlation workflows for automated incident response.

* **Intelligent Hybrid Sales Chatbot — Graduation Project (NTI, Team Project)**  
  Multi-turn conversational system built with hybrid retrieval (FAISS + BM25, Reciprocal Rank Fusion), bilingual Arabic/English intent classification, sentiment analysis, and a Gradio Blocks dashboard.

* **Production Multi-Source RAG Pipeline**  
  End-to-end question-answering engine with dense semantic embeddings, contextual chunking, ChromaDB indexing, and low-latency FastAPI endpoints.

* **PyTorch Deep Learning Implementations from Scratch**  
  Modular implementations of scaled dot-product multi-head attention, sinusoidal positional encodings, and a conditional U-Net reverse-diffusion denoising loop.

* **Predictive Maintenance Anomaly Detection**  
  Industrial sensor anomaly detection pipeline powered by XGBoost, served via asynchronous REST endpoints in FastAPI, and containerized with multi-stage Docker builds.
